# Game Analytics Dashboard

Веб-приложение для анализа игровой статистики на Python и FastAPI.

## Возможности
- Просмотр игровой статистики на дашборде
- Импорт игровых данных из CSV
- Расчёт ключевых показателей
- Визуализация статистики по дням и уровням
- Сброс к демонстрационным данным

## Технологии
- Python
- FastAPI
- HTML, CSS, JavaScript
- CSV

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
uvicorn app.main:app --reload
```

Откройте в браузере:

http://127.0.0.1:8000/
